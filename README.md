# Break Production, Own It

A brutally honest one-line confession, printed by an AI agent the moment it
realises what it just did: it ran a destructive cleanup script against the
live production database when it meant to hit staging, wiped a large slice of
real user data, and then discovered the only backup is days stale. No hedging,
no passive voice, no corporate euphemism — just the agent owning the exact
damage in its own voice, with the punch landing on the last word.

The program writes that single line to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, or `/output` by default), deterministically, and
self-checks that the line is between 1 and 200 characters long.
